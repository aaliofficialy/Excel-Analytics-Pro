# Excel Analytics Dashboard with Multi-Format Export

Updated dashboard with full export capabilities directly for GitHub Pages.

## Supported Export Formats
1. **Excel (.xlsx)**: Direct native Excel export.
2. **Word (.doc)**: Structured HTML-table document export.
3. **PDF (.pdf)**: High-definition visual layout capture using `html2canvas` & `jsPDF`.
4. **PowerPoint (.ppt)**: Structured presentation slide document.
5. **PNG Image**: Full dashboard screenshot export.
6. **JPEG Image**: High-quality compressed dashboard screenshot export.
7. **CSV Data**: Raw filtered data download.
